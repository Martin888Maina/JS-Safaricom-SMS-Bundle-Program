# Safaricom SMS Bundle Display Program

This is a simple program written in JavaScript to display the Safaricom Unlimited SMS Bundle options using the USSD code (*188#).

## Usage

1. Open the HTML file in a web browser.

2. The program will prompt you to insert the Safaricom code (188).

3. If the correct code is entered, the program will display available options for the Unlimited SMS Bundle.

4. Follow the on-screen instructions to select your preferred SMS bundle option.
